# Alimentae Website 

Alimentae is an interactive and responsive demo website for my food rescue initiative alongside my friends. A modern, responsive website for **Alimentae**, a youth-led social initiative dedicated to reducing food waste by rescuing surplus food and redistributing it to vulnerable communities in Lima, Peru. 

The website aims to raise awareness about food insecurity, explain Alimentae's mission, and encourage visitors to become part of the movement.

## About the Project

Alimentae was created to address a simple contradiction:

> Perfectly edible food is discarded every day while thousands of people struggle with hunger.

Through partnerships with local bakeries, markets, and restaurants, Alimentae rescues surplus food before it becomes waste and redistributes it to community kitchens, shelters, and families in need.

This website serves as the public face of the initiative, presenting its story, impact, values, and opportunities for collaboration.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/alimentae-website.git
```

Navigate into the project:

```bash
cd alimentae-website
```

Open the website by simply launching:

```
index.html
```

or by using a local server.

For example, with VS Code:

- Install **Live Server**
- Right-click `index.html`
- Select **Open with Live Server**
